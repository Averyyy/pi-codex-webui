## 正确性回归

重点覆盖连续权限失效、刷新响应晚到、跨范围共享文件写入屏障、模型目录投影一致性、扩展资产引用的独立释放、TUI/prompt 快照与事件合并、HTTP 域游标和 SSE transport 游标分离、冷启动 replay checkpoint、重复分页更新、Git 只读查询以及 HMR 保留事件历史。

性能指标仅用于该设备与合成负载；真实 provider 联网刷新、超长会话和其他平台应分别测量。本次验证的是源码生产构建，没有执行 npm 发布或安装包升级。
